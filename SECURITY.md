# Seguridad

Para reportar una vulnerabilidad, utilizar el reporte privado de vulnerabilidades de GitHub en este repositorio. Evitar publicar tokens, datos de clientes o detalles explotables en issues públicos.

Los cambios de dependencias y bases de imagen requieren pasar el pipeline completo. El token de instalación tiene acceso a todas las facturas y no sustituye identidad y autorización individual. El despliegue local publica solo en loopback. Ver [decisiones](docs/architecture.md) y [operación](docs/operations.md).
